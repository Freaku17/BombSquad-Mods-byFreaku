## 🎮 Features & Plugins

### 🎯 Gamemodes (5)
* **Frozen One** – Stay frozen for set time.
* **Icy Emits** – Slippery Surfaces. Explosive surprises.
* **Volley Ball** – BombSquad physics meets fast-paced volleyball action.
* **Musical Flags** – Musical chairs in BombSquad!?!!
* **Memory Game** – Test your brain and coordination.
* **Arms Race** – Cycle through different setups as you score eliminations.

### 🛠️ Utilities & Plugins (5)
* **Floater**
  * Type `/floater` directly in-game to activate.
* **IconsKeyboard**
  * Enable *"Always Use Internal Keyboard"* in `Settings → Advanced`,
  * then double-tap the space bar.
* **Terminal**
  * Shows errors for mods you're working on.
  * Open the file directly to read setup instructions.
* **TowerD-Unlocked**
  * Permanently unlocks the popular TowerD map for use in Teams and Free-for-All (FFA) modes.
* **Translate**
  * Translate yours & others chats in real-time!
  * Compatible with other party window mods like `advanced_party_window`.
  * `Single-Click` a message to translate it.
  * `Double-Click` a message to copy it to your clipboard.
  * `Double-Click` the **'Trans'** button to configure your translation preferences.
